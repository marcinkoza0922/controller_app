# Changing controls while you play

Press Guide and Start together to open the in-game menu over the game you're playing. It's built into padwight, so it works for every game. Move with the left stick or D-pad, press A to choose, and press B to go back or close it.

## Quick Settings

- left and right stick speed, for sticks that move the mouse
- gyro sensitivity, when gyro moves the mouse
- Invert Y, which flips every up-and-down setting in the profile at once
- profile, to change to another profile of the setup
- Nintendo button layout, which swaps the A/B and X/Y labels in the glyphs (for this setup)

Left and right change a number by about 10%. A flips a switch or picks the next profile.

## Edit Controls

Opens the full editor for the game in front of you: its buttons, sticks, gyro, combos, layers and macros. Changes apply straight away, but they're only written to the config file when you save.

If you close the menu with unsaved changes, you can **Save and close**, **Discard and close**, or **Keep editing**.

## When no setup matches the window

If a window is in front but no setup matches it, a change creates a new setup for that window. It's named after the program, such as `eldenring` for `eldenring.exe`, and starts from General's active profile with your change. General stays as it was.

> **Tip:** the top line of the menu shows where you are, such as `Menu › Edit Controls › A button`.
