# Sharing setups: packs and the library

A setup can be shared as a pack, a `.padpack` file. To make one, open the setup's **Details** tab and click **Export**. To use someone else's, click **+ Add setup**, then **Import a file…**.

## The library

**Add setup** lists the setups that come with padwight. Setups for games you have installed in Steam, Heroic or Lutris, and for games that are running, are listed first.

## Importing

Before anything changes, you see a preview: what's in the pack, which controller features it needs, and any name clashes with your setups. Nothing changes until you press **Save & apply**.

## Updates

When a newer version of a pack or library setup is available, the sidebar marks it with *update*. Before you update, padwight lists any changes you've made since you added the setup, because the update replaces them.

> **Tip:** a pack made with a newer padwight can't be imported. Update padwight first.
