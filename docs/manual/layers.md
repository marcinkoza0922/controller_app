# Layers

A layer is a second set of mappings that applies only while you hold a button. For example, hold LB and the face buttons type F1 to F4, while the Right Stick scrolls. Anything the layer doesn't change keeps its normal mapping.

## Turning a layer on

Choose **Layer…** as the action of any button, trigger, stick direction, zone, gesture or combo. The layer stays on while you hold that input. Wrap it in **Toggle** to keep it on until you press again.

## Layers or profiles

Use a layer when a game needs a different control scheme for part of play, such as driving or using a vehicle. Profiles stay separate from each other, so a profile should be a complete scheme on its own, and switching between schemes inside a game is what layers are for.

## Several at once

Layers can stack. If two of them disagree about a button, the one turned on most recently wins.

## Showing a layer

A layer can show its name on screen while it's on, show one of the setup's info overlays (such as a cheat sheet), or show nothing at all.

## Editing

Layers are edited on the setup's **Layers** tab. A setting the layer doesn't change reads "Same as" the profile it's shown over, with an **Override** button. **Override** lets the layer set its own value, and **Back to base** removes that value again.
